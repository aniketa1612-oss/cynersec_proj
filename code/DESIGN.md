# Design System

## Direction

Quiet incident-review room at night: neutral near-black surfaces, oxidized-teal controls, and restrained amber for attention. Dark mode is required by the project brief and supports prolonged use in a lab environment.

## Color

All application colors use OKLCH. The palette is restrained: teal marks primary actions and selection; severity colors are reserved for data states.

## Typography

Use Inter when available and the system sans stack otherwise. Keep a compact 1.125 modular scale; use tabular numerals for measurements and scores.

## Layout

A 240px desktop navigation rail collapses on small screens. Content uses a maximum width of 1440px, 24px gutters, compact summary bands, and horizontally scrollable tables.

## Components

Controls use 8px radii, visible focus rings, consistent disabled/loading states, short transitions, explicit empty states, and no decorative glass or wide shadows.
